# TTRAIL INSIDE — Revista digital

Prototipo editorial responsive para enseñar a Víctor (CEO de TTRAIL).

## Demo

Tras activar **Settings → Pages → Deploy from a branch → main / root**, la revista estará en:

https://jpinedagalvez.github.io/ttrail-inside/

## Alcance

- Revista web de una sola página, móvil y escritorio.
- Portada, historias, comunidad, retos y agenda.
- Botón para compartir por WhatsApp u otras apps mediante el diálogo nativo y copia del enlace.
- Sin compilación ni dependencias de JavaScript.
- Todos los contenidos son **piloto, pendientes de validar**. Las fotos son ilustrativas de Unsplash, no de socios ni eventos.
